CAPSTONE PROJECT PACK - CONTENTS

This pack supports a software-development capstone structured around:
1. Introduction
2. Literature Review
3. Requirements & Methodology
4. System Design & Development
5. Testing, Results & Evaluation
6. Conclusion & Recommendations

Use the folders in numeric order. Students should keep source code in Git and place supporting academic/project evidence in the matching folders.

Key assessment principle:
The project must show evidence of a real problem, justified solution, research, requirements, design, implementation, version control, testing, evaluation, final documentation, presentation and a working demonstration.
